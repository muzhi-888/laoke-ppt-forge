# 图表与配图规范

## 图表选型
| 想表达 | 用 |
|--------|----|
| 趋势随时间 | 折线图 |
| 占比构成 | 饼图/环图 |
| 多组对比 | 柱状图 |
| 排名 | 条形图 |
| 相关关系 | 散点图 |
| 流程/步骤 | 流程图 |

## 图表纪律
- 图表优先于文字：能画图不写「增长30%」，画柱状图。
- 一图一结论：每张图配一句「这张图说明 X」。
- 配色用片子主色+强调色，不彩虹。
- 坐标轴诚实：不从0截断造假，同比标基线。
- 图标题在上方，数据来源小字在下方。
- 图要有标题，无标题的图不放。

## 配图（照片/插画）
- 只用高清、授权图；不用盗图、低清图。
- 一页一图，不堆表情包、不堆图标墙。
- 图标统一线性或面性一种风格，不混搭。
- 装饰性大图放封面/过渡页，正文页少放。

## 用脚本出图位
本 skill 不内嵌绘图，但在 Markdown 大纲里用 `[图：说明]` 标图位，用户用图表生成类工具出图后手动嵌入 HTML（或后续替换占位）。脚本会把 `[图：...]` 渲染成带边框的图位提示。

## 反例
- 一页塞 3 张不相关图 → 拆页。
- 用渐变柱+立体饼+彩虹线同页 → 统一配色。
- 图无标题无来源 → 补。
