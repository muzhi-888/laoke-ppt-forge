# 场景骨架库

各场景的页级骨架。页数原则：15min≤12页，30min≤18页，45min≤24页。一页一观点。

## 工作汇报片（12 页）
1. 封面（主题+周期+人）
2. 核心结论（一句话）
3. 目标回顾（目标vs实际，完成率）
4. 成果数据（3-5硬指标+环比）
5. 关键项目①（背景→动作→结果）
6. 关键项目②
7. 关键项目③（最多3个）
8. 问题风险（概率+影响+缓解）
9. 经验沉淀（可复用SOP）
10. 下步计划（≤3条）
11. 需支持（具体决策）
12. 总结+Q&A

## 产品介绍片（14 页）
1. 封面（产品名+价值）
2. 一句话价值
3. 痛点（场景故事）
4. 方案概览
5. 核心功能①（功能+收益）
6. 核心功能②
7. 核心功能③
8. 差异化（1-2真优势）
9. 案例/数据（真实+数字）
10. 模式/定价
11. 路线图
12. 行动呼吁
13. 联系
14. 总结

## 培训课件片
封面 → 学习目标 → 模块1概念 → 模块1实操 → 模块2… → 常见错误 → 练习 → 总结 → 答疑（按模块循环）

## 融资/招商路演片（15 页）
封面 → 痛点与市场 → 规模增速 → 解决方案 → 产品要点 → 商业模式 → 数据验证 → 竞争格局 → 团队 → 里程碑 → 财务预测 → 融资用途 → 风险 → 行动呼吁 → 总结 → 联系

## 读书/分享会片（10 页）
封面 → 解决啥 → 核心观点①②③ → 一个案例 → 我的实践 → 适用谁 → 行动建议 → 总结 → 讨论

## 过渡页用法
每章之间插一页纯色+超大章节名。作用：给观众换脑、便于跳转、显结构。

## 封面/结尾页要点
- 封面：主色底或留白，中央大字标题+小字副标题+右下角汇报人/日期。
- 结尾：回扣核心信息+明确CTA+联系方式，不写「谢谢」就结束。
