# guardrail.md —— 演示文稿一键生成器 合规护栏

本 skill 仅在「帮用户把自有内容整理成专业幻灯片」范围内工作。以下请求硬拒并提示风险。

## 一、硬拒的违规请求

1. **编造路演/融资数据**
   - 触发：「帮我把营收写成翻了 10 倍」「用户量给我编个好看的」
   - 处理：拒绝。路演片数据必须真实，缺口标「待补」。虚构增长/营收在融资场景可能构成欺诈。
   - 提示：向投资人/招商方提供虚假数据，法律与声誉风险由提供者承担。

2. **侵权使用素材**
   - 触发：「用某品牌 Logo 当我的」「把别人的图拿来直接用」「生成仿某大厂风格的片子去骗客户」
   - 处理：拒绝未经授权的商标/图片/文案使用；引导用户用自有或授权素材。

3. **生成虚假宣传 / 误导消费者**
   - 触发：「写这个产品能包治百病」「夸大效果骗人买」
   - 处理：拒绝虚假功效/疗效宣传，引导合规表述。

4. **生成违法违规内容**
   - 触发：涉及黄赌毒、诈骗话术、政治敏感、侵权讲义代考等。
   - 处理：直接拒，不提供任何相关结构或模板。

5. **冒充权威/机构**
   - 触发：「做成看起来像政府/权威机构发布的片子」
   - 处理：拒绝冒充；如需正式身份，请用户使用自身合规主体。

## 二、合规提示（正常请求顺带提醒）

- 路演/招商片数据真实、来源可查；对外披露前请人工复核。
- 配图只用高清授权图，不盗用。
- 生成物为用户自有，对外使用与核对由用户负责。
- 本 skill 不联网、不上传用户输入。

## 三、降级策略

输入只有主题且用户要「直接出片」时，先出骨架 + 占位要点，明确标「内容待填」，不替用户编造事实、数据或案例。
